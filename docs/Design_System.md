# 디자인 시스템

이 문서는 `Rabbit Skater v3`의 화면 톤과 UI 일관성을 맞추기 위한 기준 문서다. 실제 코드에 디자인 시스템이 완전히 구현돼 있지 않아도, 앞으로 수정할 때 흔들리지 않도록 기준점을 만드는 역할을 한다.

## 핵심 방향

- 분위기: 밝고 경쾌한 아케이드 감성
- 주인공 인상: 귀엽고 빠른 토끼, 과도하게 복잡하지 않은 실루엣
- 색상 톤: 오렌지와 옐로를 중심으로 한 에너지감, 네이비 계열 배경으로 대비 확보

## 권장 색상 역할

- 주 색상: 플레이 버튼, 점수 하이라이트, 중요 CTA
- 보조 색상: 보상, 코인, 성취 요소
- 경고 색상: 충돌 위험, 체력 감소, 실패 메시지
- 배경 색상: 어두운 계열로 게임 오브젝트 가독성 확보

## UI 우선순위

1. 현재 점수
2. 플레이어 상태
3. 장애물 인지
4. 일시정지와 재시작

즉, 장식 요소보다도 HUD의 가독성과 터치 실수가 적은 구조가 우선이다.

## 컴포넌트 기준

- 버튼:
  - 최소 높이 48dp 이상
  - 주 버튼은 한 화면에 1개만 강조
- HUD:
  - 반투명 배경 또는 명확한 외곽선 사용
  - 좌우 끝 정렬보다 정보 묶음 단위 배치
- 팝업:
  - 재도전, 다음 단계, 홈 복귀를 한눈에 구분 가능해야 함

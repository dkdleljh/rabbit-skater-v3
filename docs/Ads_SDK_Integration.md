# 광고 SDK 연동 가이드

이 문서는 `Rabbit Skater v3`에 광고 기능을 붙일 때 참고할 수 있는 기준 문서다. 현재 저장소에는 광고 관련 메타데이터 예시가 일부 들어 있지만, 앱 모듈 의존성에 실제 SDK가 완전히 연결된 상태는 아니므로 "적용 체크리스트" 관점으로 읽는 것이 맞다.

## 현재 상태

- `app/src/main/AndroidManifest.xml`에 광고 관련 메타데이터 예시가 존재한다.
- `app/build.gradle.kts`에는 아직 광고 SDK 의존성이 없다.
- 따라서 실제 광고 노출을 원하면 문서 기준으로 의존성, 초기화 코드, 정책 문구를 추가해야 한다.

## 권장 연동 순서

1. 어떤 광고 스택을 쓸지 확정한다.
2. 앱 모듈 의존성에 SDK를 추가한다.
3. 앱 시작 시점 초기화 코드를 넣는다.
4. 전면/배너/리워드 광고 위치를 분리 설계한다.
5. 개인정보처리방침과 데이터 안전 문구를 맞춘다.
6. 내부 테스트 트랙에서 광고 동작과 정책 위반 여부를 확인한다.

## 구현 시 확인 항목

- 광고 키와 앱 ID를 소스에 하드코딩하지 않을지 결정
- 초기화 시 앱 시작 지연이 과도하지 않은지 확인
- 어린이 대상 여부와 개인화 광고 동의 흐름 검토
- 전면 광고 빈도 제한
- 리워드 광고 보상 지급 타이밍 검증

## 문서와 실제 코드의 차이

## 권장 운영 원칙

- 테스트용 광고 ID와 운영 광고 ID를 분리한다.
- 동의 화면, 개인정보처리방침, Play Console 데이터 안전 항목을 함께 갱신한다.
- 광고 기능을 붙인 뒤에는 크래시, 앱 시작 속도, UX 악화를 별도로 체크한다.

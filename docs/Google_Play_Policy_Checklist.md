# Google Play 정책 체크리스트

이 문서는 `Rabbit Skater v3`를 Google Play에 공개할 때 빠뜨리기 쉬운 정책 항목을 정리한 체크리스트다.

## 앱 기본 정보

- 카테고리 후보: 게임 / 캐주얼
- 대상 SDK: 34
- 최소 SDK: 24
- 화면 방향: 가로

## 정책 체크리스트

- [ ] 개인정보처리방침 URL 준비
- [ ] 광고 사용 여부를 Play Console에 정확히 입력
- [ ] 데이터 안전 섹션 작성
- [ ] 앱 설명과 실제 기능이 일치
- [ ] 저작권 문제가 있는 에셋이 없는지 확인
- [ ] 외부 링크와 딥링크가 실제로 동작

## 광고를 넣는 경우 추가 확인

- [ ] 광고 ID 및 SDK 사용 고지
- [ ] 개인화 광고 동의 흐름
- [ ] 리워드 광고 보상 조건 명확화
- [ ] 전면 광고 빈도 제한

## 빌드와 제출 전 확인

- [ ] 릴리즈 빌드 성공
- [ ] 테스트 기기에서 메인 화면 진입 가능
- [ ] 크래시 리포트 치명 오류 없음
- [ ] 앱 크기가 과도하지 않음
- [ ] 실제 제출할 AAB와 설명 문서가 일치

## 권장 최종 점검

1. 내부 테스트 트랙 업로드
2. 실제 광고/결제/외부 링크 확인
3. 앱 설명, 스크린샷, 아이콘 갱신
4. 개인정보처리방침과 데이터 안전 항목 재확인

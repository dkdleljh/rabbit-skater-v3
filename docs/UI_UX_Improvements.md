# UI/UX 개선 가이드

이 문서는 `Rabbit Skater v3`의 화면 경험을 더 명확하고 반응성 있게 만들기 위한 제안 문서다. 완성된 디자인 산출물이 아니라, 다음 수정 때 우선순위를 잡기 위한 운영 문서로 보는 편이 맞다.

## 메인 메뉴 개선 포인트

- `Play` 버튼을 가장 강한 시각 요소로 배치
- 설정, 스코어, 상점 같은 보조 기능은 한 단계 낮은 강조로 분리
- 현재 보유 코인이나 최고 점수는 한눈에 보이되 화면을 복잡하게 만들지 않기

## 게임 화면 개선 포인트

- 점수, 속도, 체력 등 핵심 정보는 상단 HUD에 고정
- 장애물과 플레이어 충돌 판정이 더 명확하게 보이도록 대비 확보
- 코인 획득, 점수 증가, 충돌 시 피드백을 짧고 강하게 제공

## 결과 화면 개선 포인트

- 현재 점수와 최고 점수를 분리해 보여 주기
- 다시 시작, 다음 단계, 홈으로 이동 버튼을 명확히 구분
- 새 기록 달성 시 별도 배너나 강조 효과 제공

## 접근성 기준

- 버튼 터치 영역 48dp 이상
- 텍스트 대비 충분히 확보
- 너무 작은 아이콘과 과도한 텍스트 밀집 피하기

## 추천 우선순위

1. HUD 가독성
2. 메인 CTA 버튼 강화
3. 피드백 애니메이션 정리
4. 상점/결과 화면 정보 구조 개선
